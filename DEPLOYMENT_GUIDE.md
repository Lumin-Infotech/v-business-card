# Virtual Business Card Manager - Deployment Guide\n\n## Prerequisites\n\n- PHP 8.2 or higher\n- Composer 2.x\n- Node.js 18+ with npm\n- MySQL 8.0+ or PostgreSQL\n- Git\n\n## Local Development Setup\n\n### 1. Clone and Install Dependencies\n\n```bash\ngit clone <repository-url> business-card-manager\ncd business-card-manager\n\n# Install PHP dependencies\ncomposer install\n\n# Install Node dependencies\nnpm install\n```\n\n### 2. Environment Configuration\n\n```bash\n# Copy environment template\ncp .env.example .env\n\n# Generate application key\nphp artisan key:generate\n\n# Update .env with your settings:\n# - APP_URL=http://localhost:8000\n# - DB_CONNECTION=mysql\n# - DB_DATABASE=business_cards\n# - DB_USERNAME=root\n# - DB_PASSWORD=your_password\n```\n\n### 3. Database Setup\n\n```bash\n# Run migrations\nphp artisan migrate\n\n# Seed admin user (default: admin@example.com / password)\nphp artisan db:seed --class=AdminUserSeeder\n```\n\n### 4. Build Frontend Assets\n\n```bash\n# Development build with watch\nnpm run dev\n\n# Production build\nnpm run build\n```\n\n### 5. Start Development Server\n\n```bash\n# Terminal 1: Laravel server\nphp artisan serve\n\n# Terminal 2: Vite dev server (if using npm run dev)\n# Starts automatically with npm run dev\n```\n\nAccess at: http://localhost:8000\n\n## Production Deployment\n\n### 1. Server Setup\n\n```bash\n# Update system\nsudo apt update && sudo apt upgrade -y\n\n# Install required packages\nsudo apt install -y php8.2 php8.2-cli php8.2-mbstring php8.2-xml php8.2-mysql composer nodejs npm\n```\n\n### 2. Application Setup\n\n```bash\n# Clone repository\ngit clone <repo> /var/www/business-card\ncd /var/www/business-card\n\n# Install dependencies\ncomposer install --no-dev --optimize-autoloader\nnpm install\nnpm run build\n```\n\n### 3. Environment Configuration\n\n```bash\n# Copy and configure .env\ncp .env.example .env\nnano .env  # Edit configuration\n\n# Key settings:\nAPP_ENV=production\nAPP_DEBUG=false\nDB_CONNECTION=mysql\nDB_HOST=localhost\nDB_DATABASE=business_cards\nDB_USERNAME=app_user\nDB_PASSWORD=strong_password\nMEMORY_LIMIT=256M\n```\n\n### 4. Database & Cache\n\n```bash\nphp artisan migrate --force\nphp artisan db:seed --class=AdminUserSeeder\nphp artisan config:cache\nphp artisan route:cache\nphp artisan view:cache\n```\n\n### 5. Web Server Configuration (Nginx)\n\n```nginx\nserver {\n    listen 80;\n    server_name yourdomain.com;\n    root /var/www/business-card/public;\n\n    add_header X-Frame-Options \"SAMEORIGIN\" always;\n    add_header X-Content-Type-Options \"nosniff\" always;\n\n    index index.html index.php;\n\n    charset utf-8;\n\n    location / {\n        try_files $uri $uri/ /index.php?$query_string;\n    }\n\n    location = /favicon.ico { access_log off; log_not_found off; }\n    location = /robots.txt { access_log off; log_not_found off; }\n\n    error_page 404 /index.php;\n\n    location ~ \\.php$ {\n        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;\n        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;\n        include fastcgi_params;\n    }\n\n    location ~ /\\.(?!well-known).* {\n        deny all;\n    }\n}\n```\n\n### 6. File Permissions\n\n```bash\nsudo chown -R www-data:www-data /var/www/business-card\nsudo chmod -R 755 /var/www/business-card\nsudo chmod -R 775 /var/www/business-card/storage\nsudo chmod -R 775 /var/www/business-card/bootstrap/cache\n```\n\n### 7. SSL Certificate (Let's Encrypt)\n\n```bash\nsudo apt install certbot python3-certbot-nginx\nsudo certbot --nginx -d yourdomain.com\n```\n\n## Testing\n\n```bash\n# Run all tests\nphp artisan test\n\n# Run with coverage\nphp artisan test --coverage\n\n# Run specific test file\nphp artisan test tests/Feature/AdminAuthTest.php\n```\n\n## Monitoring\n\n- Check error logs: `tail -f storage/logs/laravel.log`\n- Monitor analytics dashboard: `/admin/analytics`\n- Verify cron job for scheduled tasks\n\n## Troubleshooting\n\n1. **Database connection error**: Verify DB_* settings in .env\n2. **Permission denied**: Fix file permissions with chmod/chown\n3. **Blank page**: Check `storage/logs/laravel.log`\n4. **Missing assets**: Run `npm run build` and clear cache\n\n## Maintenance\n\n```bash\n# Clear caches\nphp artisan cache:clear\nphp artisan config:clear\nphp artisan route:clear\nphp artisan view:clear\n\n# Backup database\nmysqldump -u root -p business_cards > backup.sql\n\n# Update dependencies\ncomposer update --no-dev\nnpm update\n```\n"
