# Virtual Business Card Manager - API Documentation\n\n## Authentication\n\nAll admin endpoints require authentication via Laravel session cookies. Public endpoints are accessible without authentication.\n\n## Public Endpoints\n\n### Get Business Card\n\n**GET** `/{slug}`\n\nRetrieve a public business card by slug. Returns 404 if card is draft, inactive, or doesn't exist.\n\n**Response** (200 OK):\n```json\n{\n  \"card\": {\n    \"id\": 1,\n    \"name\": \"John Doe\",\n    \"full_name\": \"John Michael Doe\",\n    \"slug\": \"john-doe\",\n    \"title\": \"CEO\",\n    \"company\": \"Tech Corp\",\n    \"email\": \"john@example.com\",\n    \"phone\": \"+1-555-0123\",\n    \"location\": \"San Francisco, CA\",\n    \"website\": \"https://johndoe.com\",\n    \"bio\": \"Tech entrepreneur...\",\n    \"theme\": \"corporate\",\n    \"color_primary\": \"#0066cc\",\n    \"color_secondary\": \"#003366\",\n    \"color_accent\": \"#ff6600\"\n  }\n}\n```\n\n### Generate QR Code\n\n**GET** `/{slug}/qr`\n\nGenerate QR code for the business card. Logs analytics event.\n\n**Response** (200 OK): PNG image\n\n### Download Contact\n\n**GET** `/{slug}/contact`\n\nDownload vCard (.vcf) file. Logs analytics event.\n\n**Response** (200 OK): vCard file\n\n## Admin Endpoints\n\nAll endpoints require `auth` and `active.user` middleware.\n\n### Business Cards\n\n#### List Cards\n\n**GET** `/admin/cards`\n\nQuery Parameters:\n- `search` - Filter by name or slug\n- `status` - Filter by 'draft' or 'published'\n- `theme` - Filter by theme name\n\n#### Create Card\n\n**POST** `/admin/cards`\n\nRequest body:\n```json\n{\n  \"name\": \"John Doe\",\n  \"full_name\": \"John Michael Doe\",\n  \"slug\": \"john-doe\",\n  \"title\": \"CEO\",\n  \"company\": \"Tech Corp\",\n  \"email\": \"john@example.com\",\n  \"phone\": \"+1-555-0123\",\n  \"location\": \"San Francisco, CA\",\n  \"website\": \"https://johndoe.com\",\n  \"bio\": \"Tech entrepreneur\",\n  \"theme\": \"corporate\",\n  \"color_primary\": \"#0066cc\",\n  \"color_secondary\": \"#003366\",\n  \"color_accent\": \"#ff6600\",\n  \"status\": \"published\"\n}\n```\n\n#### Update Card\n\n**PATCH/PUT** `/admin/cards/{slug}`\n\nSame request body as create.\n\n#### Delete Card\n\n**DELETE** `/admin/cards/{id}`\n\n### Users\n\n#### List Users\n\n**GET** `/admin/users` (Admin only)\n\nQuery Parameters:\n- `search` - Filter by name or email\n- `role` - Filter by 'admin' or 'editor'\n- `status` - Filter by 'active' or 'inactive'\n\n#### Create User\n\n**POST** `/admin/users` (Admin only)\n\n```json\n{\n  \"name\": \"Jane Doe\",\n  \"email\": \"jane@example.com\",\n  \"password\": \"SecurePass123!\",\n  \"password_confirmation\": \"SecurePass123!\",\n  \"role\": \"editor\",\n  \"is_active\": true\n}\n```\n\n#### Update User\n\n**PATCH/PUT** `/admin/users/{id}` (Admin only)\n\n#### Delete User\n\n**DELETE** `/admin/users/{id}` (Admin only)\n\n### Analytics\n\n#### Get Dashboard\n\n**GET** `/admin/analytics`\n\nReturns aggregated analytics data:\n- Summary statistics (views, scans, downloads)\n- Events grouped by type\n- Daily statistics (last 30 days)\n- Recent events (last 10)\n\nResponse includes IP-masked events for privacy.\n\n## Status Codes\n\n- **200** - Success\n- **201** - Created\n- **204** - No Content\n- **400** - Bad Request\n- **401** - Unauthorized\n- **403** - Forbidden\n- **404** - Not Found\n- **422** - Unprocessable Entity (validation error)\n- **500** - Internal Server Error\n\n## Validation Rules\n\n### Business Card\n- `name` - Required, max 255 chars\n- `slug` - Required, unique, lowercase, alphanumeric + hyphens\n- `email` - Valid email format\n- `phone` - Valid phone format (optional)\n- `theme` - One of: corporate, gradient, minimal, dark, bold\n- `status` - draft or published\n\n### User\n- `name` - Required, max 255 chars\n- `email` - Required, unique, valid email\n- `password` - Min 8 chars, uppercase, lowercase, number, symbol\n- `role` - admin or editor\n\n## Error Response Format\n\n```json\n{\n  \"message\": \"Validation failed\",\n  \"errors\": {\n    \"email\": [\"The email field is required.\"]\n  }\n}\n```\n\n## Rate Limiting\n\nPublic endpoints: 100 requests per minute per IP\nAdmin endpoints: 1000 requests per minute per authenticated user\n\n## Webhooks (Future)\n\nSupport for webhook notifications on:\n- Card viewed\n- QR code scanned\n- Contact downloaded\n"
